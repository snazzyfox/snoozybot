# Privacy Policy

This Privacy Policy explains how Snoozybot ("the Bot") collects, uses, and protects user data when added to a Discord server or interacted with by users. 

## 1. Scope

This Privacy Policy applies solely to the instances of this bot hosted and operated by @snazzythefox on Discord, regardless of the bot's display name, avatar, or server-specific branding on individual Discord servers. If you are interacting with a self-hosted or third-party hosted instance of this software, the hosting party's privacy policy and practices apply instead.

## 2. Information We Collect

* **Discord Identifiers:** Guild (Server) IDs, Channel IDs, User IDs, and Role IDs. This information is necessary for the Bot to function properly, such as to identify the proper configuration settings for each action.
* **Personal Information You Submit** to the Bot: Some functionalities of the bot makes use of your personal information. Providing this information is completely voluntary, optional, and is not required if you do not wish to use these features. This information is used for personalized features such as birthday notifications and bedtime reminders.
* **Command & Interaction Data:** Command arguments, interaction inputs, or configuration preferences set by server administrators. This information is necessary for the Bot to function properly.
* **Your Activity in Servers:** Messages you send in public channels, your presence information, and your role assignments are used for moderation functionalities when enabled by server administrators. This information **is not** permanently stored; any such information is deleted immediately once the information is no longer needed, for example, when the user leaves the server. 
* **System Logs:** Standard diagnostic logs (error stack traces, request execution times) which may incidentally record server, channel, or user IDs for debugging purposes.

## 3. How Data is Used

Collected data is used strictly for:
* Executing requested bot commands and feature logic.
* Maintaining per-server configuration settings.
* Diagnosing technical issues and ensuring bot performance and uptime.

Ths bot **does not** collect telemetry, analytics, or any other data that does not directly contribute to the functionality of the bot. 

Any data collected by the bot is never sold, shared with third parties, or used for tracking, analytics, or advertising purposes.

## 4. Data Retention & Deletion
* **Configuration & Bot Data:** Stored until cleared by an administrator.
* **System Logs:** Rotated or deleted periodically.
* **User Submitted Information:** Stored as long as the user remains in the server. The user may delete any of such information submitted through the bot.
* **User Activity in Servers:** Stored temporarily in memory only, and automatically expires periodically.

## 4. Third-Party Services
The bot connects with Discord via the official Discord API and adheres to the [Discord Developer Terms of Service](https://discord.com/developers/docs/policies-and-agreements/developer-terms-of-service).

## 5. Contact
For questions regarding this policy or data requests, please contact @snazzythefox on Discord.
